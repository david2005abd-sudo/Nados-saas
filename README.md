# Nados — نظام إدارة التجارة الإلكترونية العراقي

Nados هو نظام متكامل لإدارة العمليات التجارية للمشاريع العراقية. يجمع الطلبات، المخزون، العملاء، التوصيل والتقارير في منصة واحدة عربية، جاهزة للعمل من المتصفح مباشرةً.

## نظرة عامة

Nados عبارة عن تطبيق ويب ثابت (HTML + CSS + JavaScript) يحاكي نظام إدارة مبيعات حقيقي، مع تجربة مستخدم حديثة ومتجاوبة مع RTL والعربية. يعمل بالكامل محلياً داخل المتصفح باستخدام `localStorage` ولا يتطلب قاعدة بيانات أو خادم خلفي في هذه النسخة التجريبية.

## المزايا الرئيسية

- **نظرة عامة شاملة**: لوحة تحكم سريعة توضح المبيعات، الطلبات، معدل التسليم، والمرتجعات.
- **إدارة الطلبات**: إنشاء طلبات يدوياً أو من المتجر، تتبع الحالة، وتفاصيل العميل والعنوان والتوصيل.
- **إدارة المنتجات والمخزون**: تتبع الكميات، تنبيهات انخفاض المخزون، إضافة منتجات بسهولة، وحالة المخزون المباشرة.
- **إدارة العملاء**: سجل شامل للعملاء، عدد الطلبات، إجمالي الإنفاق، وأداء التسليم.
- **التوصيل والتحصيل**: متابعة الشحنات مع شركات التوصيل المختلفة، وتتبع المبالغ قيد التسوية.
- **التقارير والتحليلات**: أفضل المنتجات، أفضل المحافظات، معدل التسليم/الإرجاع، ومؤشرات الأداء.
- **مساعد ذكي (Nados AI)**: ردود ذكية مبنية على بيانات تجريبية، واستفسارات عن المبيعات والمخزون.
- **مركز الدعم**: إدارة محادثات العملاء مع ردود جاهزة وأنواع التنبيهات.
- **متجر معاينة**: عرض تجريبي لتجربة التسوق للعملاء.
- **وضع الظلام**: دعم كامل لوضع الضوء والظلام مع حفظ التفضيلات.
- **متجاوب بالكامل**: يعمل بسلاسة على الهاتف، التابلت، والكمبيوتر المكتبي.

## التقنيات المستخدمة

- **Frontend فقط**: HTML5، CSS3 (متغيرات، CSS Grid/Flexbox)، JavaScript (ES6+)
- **لا يعتمد على إطار عمل**: خفيف وسريع، بدون build tools
- **حفظ محلي**: `localStorage` للبيانات التجريبية (الطلبات، المنتجات، العملاء، الإعدادات)
- **التصميم**: RTL عربي، نظام ألوان احترافي، رسوم متحركة خفيفة
- **قابل للتصدير**: تصدير طلبات بصيغة CSV، تصدير/استيراد نسخة احتياطية JSON

## تشغيل المشروع محلياً

ببساطة افتح ملف `index.html` في متصفحك، أو شغل خادم محلي بسيط:

```bash
# باستخدام Python
python3 -m http.server 8000

# باستخدام Node.js
npx serve

# باستخدام PHP
php -S localhost:8000
```

ثم افتح: [http://localhost:8000](http://localhost:8000)

**ملاحظة**: في هذه النسخة التجريبية، جميع البيانات تُحفظ محلياً في متصفحك فقط. عند مسح بيانات المتصفح أو فتح الملف في متصفح آخر، ستعود البيانات إلى قيمها التوضيحية.
